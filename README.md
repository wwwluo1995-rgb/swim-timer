# 泳鲨训练计时台

泳鲨青训的泳池边教练计时工作台（内部测试版，页面带「仅用于泳鲨青训内部测试用」水印）。整个程序就是一个文件 `index.html`，不需要安装，也不需要联网（只有字体会尝试从 Google Fonts 加载，加载不到会自动用系统字体）。

## 怎么打开

- **电脑**：双击 `index.html`，用 Chrome、Edge 或 Safari 打开。
- **手机 / 平板**：把 `index.html` 放到能用浏览器打开的地方。最方便的是开启 GitHub Pages（仓库 Settings → Pages → 选择分支），之后用网址打开，再「添加到主屏幕」。

## 功能

- **制定计划**：整段粘贴训练计划，自动识别成一组一行的清单（数量×距离、泳姿、类型、目标时间、间歇、组间休息、备注一眼看完），点哪一组就展开改哪一组，可排序、复制、增删。
  - 时间可以填秒数（`55`、`90`），也可以填分:秒（`1:30`）；目标留空 = 手动计时。
  - 替换、清空、删除、从计划库载入之后都有「撤销」，点错了不会丢计划。
  - 能识别：`8×50`、`4个25`、`200自双臂橹手`、`55标`、`43秒标`、`25间歇`、`组间2分`、`3组8个50`（套用到下面几行）、`同上`。
- **自定义项**：不想按「数量×距离 + 泳姿 + 类型」模板写的内容（如「200 混合泳」「出发练习」「陆上拉伸」），可以用「＋ 自定义项」或在卡片上切到「自定义」，名称随便写、距离可填 0（不计入总量）。整段输入里以 `自定义：` 或 `+` 开头的行也会识别成自定义项。
- **计划库**：常用计划可「保存到计划库」，随时一键载入；每次开始训练会自动记一条训练记录（含现场改过的最终计划、是否完成），可搜索、改名、删除、把记录存为常用计划。计划库保存在当前设备的浏览器里。
- **训练计时**：深色记分牌式大字倒计时，游进 / 间歇 / 组间休息自动切换；显示总进度、每组趟数、下一步。
  - 训练中可直接点「调整计划」或进度列表里的铅笔按钮现场改计划，计时不中断。
  - 准备 / 间歇 / 组间休息时可以点「−10″ / +10″」只调这一次，不改计划。
  - 手动计时的组，右边的按钮会变成醒目的「到边」。
  - 中途刷新页面或浏览器被系统关掉，再打开会回到原来的那一步（暂停状态），点「继续」接着计时；到边成绩也还在。
  - 点进度列表跳组后可以「回到刚才」；训练结束后可直接看成绩表、复制成绩、存为常用计划。
  - 组间休息时有 10 秒测心率计数。
  - 独立的间歇秒表（倒计时 / 正计时）。
- **提醒**（可同时开启）：
  - 报时（倒计时）：每 N 秒报剩余时间，可设「从剩多少秒开始报」和「最后多少秒每一秒都报」（默认最后 5 秒；设成 10 就是「十、九、八、七、六、五、四、三、二、一」，10 到 6 只报数字、不带「秒」）。
  - 报时（正计时，手动计时的组和正计时秒表）：可设「从第几秒开始报」，前面不出声（默认第 30 秒）；还可设「从第几秒起每一秒都报」（最多报到 59 秒）。超过 1 分钟后每半分钟报一次。
  - 以上是默认值，每一组都可以在计划里单独设置。
  - 间隔出发：每隔 N 秒报「2 号出发」「3 号出发」……
- **按泳道设目标**：「出发顺序」里每条道有「目标」，按每 100 米比计划的目标快几秒或慢几秒（例：第 2 道慢 5″，8×50 目标 55″ 就变成 57″5）。计时屏、到边按钮、成绩表和复制的成绩都按各道自己的目标比快慢；计时和出发间隔仍按计划的目标。点到边区左边的「N道」也能打开这个设置。
- **到边计时**：不开间隔出发也有（大家一起出发，按到边记每个人的成绩）；不需要时点「收起」，要再打开在「出发顺序」里打开「到边计时」。电脑和平板上点「放大」把它放到屏幕中间（Esc 或点旁边缩回），点「排人」时自动放大。间隔出发时：所有泳道、所有学生的「到边」按钮都放在同一张固定大小的卡片里，不用上下滑动；人越多按钮自动越小（每道左边标「1道」「2道」）。可增加泳道（最多 8 道同时出发，每道人数单独设），每个学生一个「到边」按钮；训练计时页工具栏的「出发顺序」可开关间隔出发、调间隔和人数，并用下拉框从学员名单里选每个位置的学生，点一下自动扣掉他晚出发的秒数，记下他自己的成绩（精确到百分之一秒，如 1:35″33），并显示「比目标快/慢」多少；可撤销；「成绩表」按趟列出每人成绩、平均和最快；成绩随训练记录一起保存在计划库。电脑上每条道用一排键记到边（见下面「到边快捷键」）。
  - 每组可单独设置报时：每 5/10/15/20/30 秒或每 1 分钟、范围（30 秒以内到全程），或这一组不报时；不设就跟随默认。
  - 提示方式：哨声 / 语音 / 哨声 + 语音。
- **内置语音包**：语音直接嵌在页面里离线播放，不依赖设备的语音引擎，不会卡顿漏报。
- 适配手机、平板、电脑，浅色 / 深色模式；屏幕常亮；空格开始/暂停，← → 切换步骤。

- **工具箱**（导航第 4 项）：点「工具箱」先看到所有工具的卡片（带缩略图和当前状态，例如「进行中：第 2 组 · 第 3 趟」「已测 8 人」），点卡片进入工具，左上角「‹ 工具箱」返回。电脑上左侧栏「工具箱」可以展开，直接点进某个工具。
  - **依次出发 · 分组平均**：组数、每组趟数、距离、泳道数、每道人数、出发间隔都直接在卡片上点加减设置。每趟点「出发」，同一道的学生按间隔一个一个出发、各道同时出发；学生到边点他的按钮记成绩。一组游完自动算每个人这一组的平均，下一组每一趟都和上一组平均比，比平均慢的标红。可停表、重来这一趟、回到上一趟、撤销；成绩自动存进「计划库 → 训练记录」，可复制成文字。中途刷新不丢已记的成绩。
  - **出发间隔 0 秒 = 一批一批出发**：每条道的 1 号是第 1 批，点「出发」放这一批；这一批到边后再点「出发」放第 2 批，每一批从自己出发的那一下开始计时。（训练计时页里间隔 0 秒是同一道的人一起出发。）
  - **加人、加道、减人都在到边区里**（手机、平板、电脑一样）：每条道最后一个名字后面有一个虚线「＋」框，点一下这条道加 1 人；所有泳道下面有一条虚线「＋ 加一条泳道」；上面那一排的「减人」点一下，再点要减掉的人（后面的人往前补，已记的成绩跟着人走），或点左边的「N道」连点两次减掉整条道，减完点「减好了」。每次减掉都可以「撤销」。表在走的时候这些都收起来，按钮会更大。训练计时页里这些在「排人」里。
  - **计时界面里直接排人、改人数**：电脑和平板上，名字小卡片一直在到边区上方，表没在走的时候随时可以拖到位置上，或在位置之间互相拖着换；每条道的人数和泳道数也在那一行直接加减。表在走的时候这一行会变淡锁住，防止误拖。手机上屏幕放不下，点「排人」打开一屏的排人界面，排好点「排好了」。
  - **都到边自动停表**：这一批（间隔 0 秒）或这一趟（有间隔）的人全部按了到边，表自动停。撤销最后一次到边，表会从原来的出发时刻接着走。已经用了名字时，没排人的空位不算人。
  - **防误触**：出发后只能记正在游的人——间隔 0 秒时只有这一批的位置能点，别的批点了没反应并提示；已经记了成绩的人不会被再点一次覆盖，要改先「撤销」（可以连续撤销多次）。间隔 0 秒用键盘时，一条道的整排键都记这一批的那个人，按到旁边的键也不会记到别人头上。训练计时页同样不会覆盖已记的成绩。
  - **下一趟 / 跳过这一批**：「下一趟」= 这一趟不游（间歇一趟），不计时直接到下一趟，没成绩的趟不算进平均。间隔 0 秒时还有「跳过这一批」= 这一批这一趟不游。
  - **快捷键显示在名字前面**：电脑上每个位置的名字前面有一个小键帽（1、Q、A、Z 各一排）。
  - **学员名单**：名字可以整段粘贴，用换行、空格、逗号、顿号、句号、分号隔开都行。
  - **排人（拖学员卡片）**：到边区点「排人」，名单里的每个学员是一张卡片，拖到某条道的某个位置上就定下来了（也可以先点学员、再点位置；位置之间互相拖是交换，拖回上面是拿下来）。训练计时页的到边区也有「排人」。
  - **顺序固定 / 每组重排**：排人时可选。「顺序固定」各组都用同一个排法；「每组重排」每一组结束后自动打开排人，重新拖一遍再出发。换了泳道或位置，平均成绩仍然跟着学生本人走，下一组还是和他自己上一组的平均比。
  - **CSS 配速**：给每个学生测一次 CSS（临界游速）：全力游 400 米和 200 米（也可选 200+100、200+50）各计一次时间，填进表里，软件算出每 100 米的 CSS 配速。选强度区（EN1 有氧、EN2 阈值、EN3 最大摄氧、恢复）和每趟距离，列出每个人的目标时间和建议出发间隔，可复制。每个区比 CSS 快 / 慢几秒、每趟休息几秒都能改。在「依次出发 · 分组平均」里选一个强度区，到边按钮就显示每个人自己的目标，到边后比目标快还是慢，慢了标红；没测过的学生仍和上一组平均比。测试记录会保留历史，用最新一次，备份时一起导出。
  - **分段秒表**：开始 / 暂停、分段、复位；列出每段时间和累计，标出最快、最慢；可复制。刷新页面后继续走表。
- **到边快捷键**（电脑）：每条道一排键，键在这一排里的位置就是出发顺序——第 1 道 `1`–`0`，第 2 道 `Q`–`P`，第 3 道 `A`–`;`，第 4 道 `Z`–`/`；`退格` 撤销。训练计时页和工具箱都能用，按钮左上角会显示对应的键。
- **复制成绩**：成绩表、训练结束页和训练记录里都能「复制成绩」，得到一人一行的文字，直接粘贴到微信。
- **备份**：计划库页底部可「导出备份」成一个文件，在另一台设备上「导入备份」（合并，不会覆盖已有内容）。
- **日间 / 夜间模式**：两套配色，侧栏底部（手机在右上角）一键切换；第一次打开跟随系统，之后记住你的选择。日间是浅色底配深色大字，夜间是深色底配发光大字。

- **手机 / 平板上点得再快也不会放大缩小**：关掉了双击放大和双指缩放（单指滑动不受影响），输入框获得焦点时也不再自动放大。到边按钮每根手指各算一次，两个人同时到边可以两根手指一起点；成绩按手指按下的那一刻计。
- **版本和自动更新**：侧栏底部和计划库页底部显示「版本 X月X日 时:分」（这份页面的发布时间）。打开页面时会自动检查有没有更新的版本，有就自动换成新版；训练计时进行中不会自动换，只提示「有新版本 · 更新」。

计划和设置保存在当前设备的浏览器里；换设备用「导出备份 / 导入备份」。

## 语音包说明

- 软件会播报的全部 90 句都是教练本人录音（1.2 倍速、音调不变），内嵌在 `index.html` 里离线播放：
  - 倒数：五、四、三、二、一
  - 提示：出发、准备、间歇、组间休息测心率、训练完成、开始、继续、停、开始数心率、时间到出发、提示音已打开
  - 间隔出发：一号出发 … 十号出发
  - 秒数：一秒 … 五十九秒；一分钟、一分半、两分钟、两分半、三分钟
- 不会调用设备的语音引擎，也不会混入合成声音；万一遇到没录的内容，只吹一声短哨。
- 「从剩多少秒开始报」最多 60 秒；间歇时长不在上面列表里时，只报「间歇」。
