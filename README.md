# 长训队泳池计时台

泳池边用的教练计时工作台。整个程序就是一个文件 `index.html`，不需要安装，也不需要联网（只有字体会尝试从 Google Fonts 加载，加载不到会自动用系统字体）。

## 怎么打开

- **电脑**：双击 `index.html`，用 Chrome、Edge 或 Safari 打开。
- **手机 / 平板**：把 `index.html` 放到能用浏览器打开的地方。最方便的是开启 GitHub Pages（仓库 Settings → Pages → 选择分支），之后用网址打开，再「添加到主屏幕」。

## 功能

- **制定计划**：整段粘贴训练计划，自动识别成分组卡片（数量×距离、泳姿、类型、目标时间、间歇、组间休息、备注），可逐组微调、排序、增删。
  - 能识别：`8×50`、`4个25`、`200自双臂橹手`、`55标`、`43秒标`、`25间歇`、`组间2分`、`3组8个50`（套用到下面几行）、`同上`。
- **训练计时**：深色记分牌式大字倒计时，游进 / 间歇 / 组间休息自动切换；显示总进度、每组趟数、下一步。
  - 训练中可直接点「调整计划」或进度列表里的铅笔按钮现场改计划，计时不中断。
  - 组间休息时有 10 秒测心率计数。
  - 独立的间歇秒表（倒计时 / 正计时）。
- **提醒**（可同时开启）：
  - 倒数报时：每 N 秒报剩余时间，最后 5 秒报「五、四、三、二、一」。
  - 间隔出发：每隔 N 秒报「2 号出发」「3 号出发」……
  - 提示方式：哨声 / 语音 / 哨声 + 语音。
- **内置语音包**：语音直接嵌在页面里离线播放，不依赖设备的语音引擎，不会卡顿漏报。
- 适配手机、平板、电脑，浅色 / 深色模式；屏幕常亮；空格开始/暂停，← → 切换步骤。

计划和设置保存在当前设备的浏览器里，换设备需要重新输入。

## 语音包说明

- 常用的 37 句（倒数、出发、准备、间歇、组间休息测心率、训练完成、常用秒数、1–10 号出发等）是教练本人录音，1.2 倍速、音调不变。
- 其余秒数由离线语音合成补齐（[zhtts](https://pypi.org/project/zhtts/)，MIT 许可；其模型基于标贝公开中文语音数据训练，该数据通常仅限非商业用途）。如需商用，建议把剩余秒数也换成真人录音。
